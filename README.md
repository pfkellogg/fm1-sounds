# FM-1 Big Screen sounds, for the web

The Mellotron-style sounds of [FM-1 Big Screen](https://github.com/pfkellogg/fm1-mirror), served by GitHub Pages so
web pages can play them: `sounds/<id>/043.flac` ... `077.flac` (one 8-second tape strip per key, G2 to F5), and
`index.json` (the list). Played live from an M-VAVE FM-1 at [aikellogg.com/#/play](https://aikellogg.com/#/play).

Made from scratch by programs (no recordings): `tools/make_mellotron_*.py` in
[fm1-mirror-spyglass-android](https://github.com/pfkellogg/fm1-mirror-spyglass-android). Free to use in your own music.
